# PhishPhilter - A Phishing detection Chrome Extension

This extension was created as a capstone project for the 2025-2026 Academic year

PhishPhilter works by getting emails from a user's inbox, scanning it with a list of common phrases found in industry specific phishing emails, and returning to the user the results

It uses a Javascript based extension, a Powershell script for the email connection, and a Python program for scanning the emails
